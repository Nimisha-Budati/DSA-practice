AND
a & b
→ both bits must be 1

OR
a | b
→ at least one bit is 1

XOR
a ^ b
→ different bits give 1

NOT
~a
→ flips bits

LEFT SHIFT
a << i
→ shift left
→ approximately a × 2^i

RIGHT SHIFT
a >> i
→ shift right
→ approximately a / 2^i


Check i-th bit:
n & (1 << i)

Set i-th bit:
n | (1 << i)

Clear i-th bit:
n & ~(1 << i)

Toggle i-th bit:
n ^ (1 << i)

Odd:
n & 1

Power of 2:
n > 0 && (n & (n - 1)) == 0

Remove lowest set bit:
n & (n - 1)

Count set bits:
while(n)
{
    n = n & (n - 1);
    count++;
}
